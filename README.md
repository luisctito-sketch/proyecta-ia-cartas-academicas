# PROYECTA-IA · Cartas Académicas

Chatbot transversal para estudiantes de Taller de Tesis II de Ingeniería Electrónica - UPEA.

## Repositorio recomendado
`proyecta-ia-cartas-academicas`

## GitHub Pages
`https://luisctito-sketch.github.io/proyecta-ia-cartas-academicas/`

## IMPORTANTE: subir todos estos archivos a la RAÍZ del repositorio
- `index.html`
- `styles.css`
- `app.js`
- `01_Carta_Aval_Tutor_Modelo_1.docx`
- `02_Carta_Aval_Tutor_Modelo_2.docx`
- `03_Solicitud_Cambio_Titulo_Objetivos_Modelo_1.docx`
- `04_Solicitud_Cambio_Titulo_Objetivos_Modelo_2.docx`
- `.nojekyll`

Los cuatro Word están también duplicados dentro de `plantillas/` como respaldo, pero la web descarga las copias de la raíz para evitar errores de rutas cuando se sube el repositorio desde el navegador de GitHub.

## Acceso
Se mantiene el sistema centralizado de acceso de PROYECTA-IA y se carga:
`https://luisctito-sketch.github.io/proyecta-ia-acceso/access.js`

## Activar GitHub Pages
Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)`.

Si ya existe el repositorio, reemplazar `index.html` y subir los cuatro archivos DOCX a la raíz. No es necesario cambiar la URL pública del chatbot.
