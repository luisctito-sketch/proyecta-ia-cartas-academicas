# PROYECTA-IA · Cartas Académicas

Chatbot transversal para la Carrera de Ingeniería Electrónica - UPEA.

## Funciones
- Explica cuándo corresponde una carta-aval del tutor y una solicitud de modificación de título/objetivos.
- Incluye cuatro modelos Word editables y descargables.
- Permite revisión preliminar de estructura mediante texto pegado o carga de TXT, DOCX y PDF.
- Conserva el esquema de acceso central de PROYECTA-IA: cada chatbot exige una nueva autenticación por C.I.
- No utiliza ni incorpora firmas escaneadas.
