# Integración en el portal principal de PROYECTA-IA

Agregar esta tarjeta dentro de la sección **Chatbots transversales**, junto a APA y los otros módulos transversales.

```html
<a class="module-card transversal" href="https://luisctito-sketch.github.io/proyecta-ia-cartas-academicas/">
  <div class="module-icon">✉️</div>
  <div class="module-content">
    <span class="module-kicker">CHATBOT TRANSVERSAL</span>
    <h3>Cartas académicas</h3>
    <p>Carta-aval del tutor, cambio de título y objetivos, modelos Word editables y revisión preliminar.</p>
  </div>
</a>
```

Si el portal utiliza navegación relativa desde el mismo usuario de GitHub, también puede emplearse:

```html
<a class="module-card transversal" href="../proyecta-ia-cartas-academicas/"> ... </a>
```

**Recomendación:** mantener la navegación en la misma ventana, igual que los demás módulos de PROYECTA-IA.
